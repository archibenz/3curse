# 🧩 Maze Generator — DAGA Project (4 семестр)

Приложение для генерации и визуализации лабиринтов с многопоточной синхронизацией. Доступны две версии: **Desktop (Qt)** и **Web**.

---

## 📁 Структура проекта

```
proj/
├── src/maze/           # C++ исходники (генерация, GUI, поиск пути)
├── web/
│   ├── backend/src/    # Java веб-сервер
│   └── frontend/       # HTML/CSS/JS интерфейс
├── scripts/            # Скрипты установки и графиков
├── build/              # Директория сборки (создаётся CMake)
├── outputs/            # Результаты тестов и графики
└── assets/             # Примеры данных
```

---

## 🌐 Web-версия (рекомендуется для быстрого тестирования)

### Требования
- **Java 11+** (проверить: `java -version`)

### Запуск

```bash
# 1. Перейти в папку backend
cd web/backend

# 2. Скомпилировать Java-сервер
javac src/Main.java

# 3. Запустить сервер
java -cp src Main
```


### Открыть в браузере

Скопируйте URL из консоли (например, `http://localhost:8080`) и откройте в браузере.

### Функционал Web-версии

| Вкладка | Описание |
|---------|----------|
| **Генерация** | Создание лабиринтов (классический, неидеальный, многопоточный) |
| **Экспорт** | Скачивание в PNG, JPEG, SVG, JSON для робототехники |
| **Бенчмарки** | Сравнение скорости генерации с разным числом потоков |
| **О проекте** | Описание алгоритмов и технологий |

### Тестирование Web-версии

1. **Генерация лабиринта:**
   - Выберите алгоритм (Классический / Неидеальный / Многопоточный)
   - Установите размер (ширина × высота)
   - Нажмите "Сгенерировать"
   - Путь от старта до выхода анимируется автоматически

2. **Экспорт:**
   - Перейдите на вкладку "Экспорт"
   - Выберите формат (PNG/JPEG/SVG/JSON)
   - Настройте цвета и размер ячейки
   - Нажмите "Скачать"

3. **Бенчмарки:**
   - Перейдите на вкладку "Бенчмарки"
   - Нажмите "Запустить тест"
   - Дождитесь отрисовки графика

### Остановка сервера

Нажмите `Ctrl+C` в терминале.

## 🖥️ Desktop-версия (Qt GUI)

### Требования
- C++17 компилятор (GCC / Clang / MSVC)
- CMake 3.16+
- Qt 6 (модуль Widgets)
- *(Опционально)* Python 3 + matplotlib — для графиков

### Сборка

```bash
# Из корневой папки проекта
cmake -S . -B build
cmake --build build
```

### Запуск

```bash
./build/maze_gui
```

На macOS можно также:
```bash
open build/maze_gui.app
```

### Тестирование Desktop-версии

1. **Меню "Построение лабиринтов":**
   - Классический (идеальный) 20×20
   - Неидеальный (многопоточный) 20×20
   - Идеальный (многопоточный + синхронизация)
   - Произвольный размер

2. **Меню "Описание":**
   - Построение лабиринта
   - Поиск кратчайшего пути
   - Потоки при построении / поиске пути
   - Синхронизация (уровни и точки)

3. **Меню "Графики":**
   - 1..N потоков: сравнение скорости
   - Фикс. потоки: синхр. vs без синхр.
   - Результаты сохраняются в `outputs/`

4. **Меню "Веб-интеграция":**
   - Инструкция по запуску Web-версии

## 🔧 Troubleshooting

| Проблема | Решение |
|----------|---------|
| `java: command not found` | Установите JDK 11+: `brew install openjdk` (macOS) |
| `Port already in use` | Сервер автоматически пробует порты 8080-8095 |
| Qt не найден | Установите Qt 6: `brew install qt` (macOS) |
| Графики не создаются | Установите matplotlib: `pip3 install matplotlib` |

## 📊 Алгоритмы

| Алгоритм | Описание | Сложность |
|----------|----------|-----------|
| **DFS-Backtracking** | Поиск в глубину с откатом, идеальный лабиринт | O(W×H) |
| **Imperfect** | DFS + случайное удаление стен для петель | O(W×H) |
| **Multithread** | Параллельная генерация с барьерами синхронизации | O(W×H / N) |
| **BFS Pathfinding** | Поиск в ширину, гарантирует кратчайший путь | O(W×H) |
