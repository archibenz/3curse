Информация о тестах

Синхронизированные потоки

Потоки работают на общей структуре данных с использованием барьеров синхронизации. Это позволяет генерировать один большой лабиринт параллельно.

Независимые потоки

Каждый поток генерирует свой собственный небольшой лабиринт. Нет накладных расходов на синхронизацию, но результат — несколько маленьких лабиринтов.

Параметры теста

  • Размер лабиринта: 30×30
  • Количество прогонов: 3
  • Потоки: 1, 2, 4, 6, 8
